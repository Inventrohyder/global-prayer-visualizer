# Global Prayer Visualizer

Interactive 3D globe + 2D map prayer-time tool with jurisdiction-aware method selection, time scrubbing, timezone/elevation aware point inspection, and solar day/night visualization.

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Checks
```bash
npm run lint
npm run type-check
npm run test
```
