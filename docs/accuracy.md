# Accuracy Notes

## Exact
Clicked-point prayer times, timezone formatting, method selection, high-latitude notices, and optional elevation adjustment are computed with deterministic code paths.

## Approximate
Current world overlay demarcation curves are sampled visual guidance lines rather than fully solved global contour fields per method/tile.

## Terrain handling
Point elevation adjustment is implemented. Terrain-adjusted global overlays are not yet fully enabled.

## Official timetable differences
Official authority tables can differ due to local administrative offsets, iqama policy, observation rules, and region-specific conventions.

## Fallback labels
"fallback" indicates method/jurisdiction defaults were inferred due to missing source data.
